## 1. 通用约定

### 1.1 基础

| 项 | 约定 |
|---|---|
| 前缀 | `/api` |
| 格式 | JSON，`Content-Type: application/json` |
| 时间 | 日期 `yyyy-MM-dd`；时刻 `yyyy-MM-dd HH:mm:ss`；`due_time` 用 `HH:mm` |
| 金额 | **传输用「分」的整数**，字段名以 `Cents` 结尾；前端展示时 ÷100 |
| ID | 字符串（后端 Long → 序列化为 String） |
| 排序 | 写操作返回 204 或受影响行数；列表统一 `list + total` |

### 1.2 响应体

```json
{
  "code": 0,
  "message": "ok",
  "data": {},
  "traceId": "a1b2c3d4",
  "timestamp": 1762900000000
}
```

| code | 含义 |
|---|---|
| 0 | 成功 |
| 40001 | 参数校验失败（`data.errors` 为字段级错误） |
| 40101 | 未登录 / token 过期（`NotLoginException`，前端清 token 跳登录） |
| 40102 | token 无效（JWT 签名或格式错误） |
| 40301 | 无权限（`NotPermissionException` / `NotRoleException`） |
| 40302 | 账号被禁用（`DisableServiceException`） |
| 40303 | 登录失败次数过多，临时锁定（15 分钟） |
| 40401 | 资源不存在（**越权一律返回此码**，不返回 403） |
| 42901 | 限流 |
| 50000 | 服务异常 |
| 60001+ | 业务错误（60001 天气 Key 无效、60002 知识库连接失败、60003 备份文件损坏、60020 注册已关闭、60021 首个管理员已被领取…） |

### 1.3 分页

请求：`?page=1&size=20`（page 从 1 起，size ≤ 100）
响应：

```json
{ "list": [], "total": 128, "page": 1, "size": 20 }
```

### 1.4 鉴权（Sa-Token）

除白名单外，请求头必须带：

```
MiniDesk-Token: {tokenValue}
```

- Token 由 `POST /api/auth/login` 下发，JWT 无状态，服务端不存会话
- 有效期 30 天；剩余不足 3 天时响应头返回 `X-Token-Renew: 1`，前端调 `/auth/renew` 静默续期
- 白名单：`POST /api/auth/login`、`POST /api/auth/register`、`GET /api/auth/register-config`、`POST /api/auth/renew`、`GET /api/ping`、`GET /api/files/{id}/thumb`
- 全局校验：`/api/**` 统一走 `SaRouter.match(...).check(r -> StpUtil.checkLogin())`，不在每个方法上写登录判断

### 1.5 权限码

写接口统一用 `@SaCheckPermission("模块:资源:动作")` 标注，动作限 `query / add / update / delete / export / import / manage`。

| 域 | 权限码示例 |
|---|---|
| 工作 | `work:task:add`、`work:project:delete`、`work:meeting:manage`、`work:review:generate` |
| 学习 | `study:plan:update`、`study:record:add`、`study:kb:query` |
| 生活 | `life:ledger:add`、`life:ledger:export`、`life:trip:manage` |
| 公共 | `shared:file:upload`、`shared:search:query` |
| 系统 | `system:user:manage`、`system:role:manage`、`system:backup:restore`、`system:job:run`、`system:integration:update`、`system:audit:query`、`system:monitor:query`、`system:dashboard:query` |

- 无权限返回 `40301`
- 未标注解的业务写接口视为缺陷，CI 的接口自检会失败
- 内置角色：`ADMIN`（`*`）、`MEMBER`（`work:*` / `study:*` / `life:*` / `shared:*`）

## 2. 认证与账号

| 方法 | 路径 | 说明 |
|---|---|---|
| POST | `/auth/login` | 登录，返回 token + 用户信息 + 角色权限码 |
| POST | `/auth/register` | **自助注册**，成功后直接返回 token（首个注册者为 ADMIN） |
| GET | `/auth/register-config` | 注册页所需状态（是否开放、是否首个用户、是否需 claim token、密码策略） |
| POST | `/auth/renew` | 续期（`StpUtil.renewTimeout`），无需重新登录 |
| POST | `/auth/logout` | 注销（`StpUtil.logout`，JWT 模式下前端丢弃即可） |
| GET | `/user/me` | 当前账号信息 + 设置 + 权限码 |
| PUT | `/user/me` | 改昵称、头像、邮箱 |
| PUT | `/user/password` | 改密码（需旧密码） |
| GET | `/user/accounts` | 本机已登录账号列表（用于快速切换，存前端 + 服务端校验） |

```json
// POST /api/auth/login
{ "username": "cosolar", "password": "******", "remember": true }

// 200
{ "code": 0, "data": {
  "tokenName": "MiniDesk-Token",
  "tokenValue": "eyJhbGciOi...",
  "expiresIn": 2592000,
  "user": { "id": "1", "username": "cosolar", "nickname": "朋友", "avatarUrl": null },
  "roles": ["MEMBER"],
  "permissions": ["work:*", "study:*", "life:*", "shared:*", "system:setting:update"]
}}
```

> 前端拿到 `permissions` 后存 `userStore`，用于 `v-permission` 指令与按钮显隐；**显隐只是体验，后端注解才是权限边界**，两者不可互相替代。

```json
// GET /api/auth/register-config
{ "code": 0, "data": {
  "allowRegister": true,
  "isFirstUser": true,
  "needClaimToken": false,
  "passwordPolicy": { "minLength": 8, "requireLetter": true, "requireDigit": true }
}}
```

```json
// POST /api/auth/register
{ "username": "cosolar", "nickname": "朋友", "password": "******", "confirmPassword": "******", "claimToken": null }

// 200（结构与 login 一致，便于前端复用）
{ "code": 0, "data": {
  "tokenName": "MiniDesk-Token", "tokenValue": "eyJ...", "expiresIn": 2592000,
  "user": { "id": "1", "username": "cosolar", "nickname": "朋友" },
  "roles": ["ADMIN"],
  "permissions": ["*"],
  "isFirstUser": true
}}
```

- 注册成功后**直接登录**，不要求再输一次密码
- 库中已有用户 → 返回 `roles: ["MEMBER"]`、`permissions: ["work:*","study:*","life:*","shared:*"]`
- 注册关闭 → `60020`；首个管理员已被领取但请求带了 claim 意图 → `60021`
- 同 IP 每小时超过 3 次 → `42901`

|---|---|---|---|
| GET | `/tasks` | 列表 | `module, taskType, status, projectId, planId, dueDate, keyword, page, size` |

```json
// POST /api/tasks
{
  "module": "work",
  "taskType": "todo",
  "title": "完成 MiniDesk 设计稿",
  "note": "",
  "priority": 1,
  "dueDate": "2026-10-08",

  "repeatRule": null,
  "remindAt": null,

```

**重复任务**：`repeatRule` 传 iCal RRULE，例如 `FREQ=WEEKLY;BYDAY=MO,WE,FR`。创建时后端存母任务（`series_id = null`），由 `RecurringTaskJob` 每日展开当日实例。

## 10. 知识库（MiniDocs 代理）

> 本节已按线上实际契约重写。旧版里的 Halo Console API / Halo PAT / `/kb/list` 等路径
> 在当前 MiniDocs 中不存在，属设计蓝图残留。

上游：`https://docs.minims.cn/api`（可配置，填站点根自动补 `/api`），
请求头 `Authorization: Bearer mdt_xxx`。`/console/{org}/...` 需令牌，
`/portal/...` 为匿名白名单。上游统一信封 `{code,message,data}`，
分页为 `?page=1&size=N` + `data.list / data.total`。

### 10.3 约束与错误码

- 令牌加密存 `integration_config`（`provider=minidocs`），只回显掩码；明文不进日志、不回前端。
- 正文不缓存；目录树缓存 5 分钟；写操作后主动失效。
- 只读令牌调用写接口返回 `60063`；令牌失效 / 被吊销映射为 `60061`。
- 错误码：`60060` 未配置或未启用、`60061` 令牌无效、`60062` 上游请求失败、`60063` 只读令牌。
- 令牌不能用于上游 `/api/tokens` 与账号安全类接口；签发与吊销只能在知识库网页端完成。

### 14.6 审计埋点要求

> **已实现（2026-11-13）**：`AuditAspect` 环绕所有 `modules..controller` 的

```java
@AuditLog(module = "console-user", action = "reset-password", targetType = "user")

```

- 配置键写在 `sys_config`：`smtp_host/port/username/password(加密)/from/ssl` 与 `mail_enabled`。

## 18. 实现注意

1. **越权返回 404**：详情接口被租户条件过滤后查不到，统一抛 `40401`，不要抛 403，避免探测。
2. **并发与幂等**：`POST /tasks`、`POST /ledger` 支持 `X-Request-Id` 去重（前端 axios 已注入），5 秒内同 ID 直接返回上次结果。
3. **乐观更新**：仅 `PATCH /tasks/{id}/done` 与 `PATCH /shopping/items/{id}/bought` 做前端乐观更新，其余等接口返回。
4. **日历聚合上限**：单次区间最多返回 500 条，超出截断并置 `truncated: true`。
5. **导出走异步**：生成百万级 Excel 会阻塞，必须用线程池 + 状态轮询。
6. **所有写接口返回受影响行的最新版本**，便于前端 `setQueryData` 精准更新而不必整表刷新。
